# RestOs — User Flow Script

A short, video-ready walkthrough of what a user actually does in RestOs.
Read it top to bottom — each step is one beat of the story.

---

## 1. Arrive & Sign in
- User lands on RestOs.
- Signs up / logs in → a **User** account is created.
- This account is the anchor — everything they do links back to it.

## 2. Set up the profile (optional)
- Adds a photo, bio, location, cuisine preferences.
- Picks dietary needs and preferred meal times.
- → Makes recommendations feel personal.

## 3. Browse the food
- Opens the menu, filtered by **Food Category**.
- Scrolls dishes: price, rating, veg/spicy/gluten-free tags.
- Reads **Reviews** left by other diners on each dish.

## 4. Pick & add to cart
- Chooses a dish, sets the quantity.
- Adds it to the cart → this becomes an **Order** (status: pending).
- Can keep adding more dishes to the same checkout.

## 5. Checkout & pay
- Reviews the cart total.
- Pays → a **Payment** is created and the Order is settled.
- One payment can cover several orders at once (batch checkout).
- Order status moves: pending → confirmed.

## 6. Engage with the community
- Writes a **Blog** post (a recipe or food story).
- Others **Comment** on it; comments can have **Replies**.
- Posts collect **Votes** (upvotes / downvotes).
- User can **Save** (bookmark) any blog or dish to revisit later.

## 7. See the dashboard
- Opens their dashboard / profile overview.
- Sees stats: their orders, saved items, blogs, comments, upvotes received.
- **Analytics** quietly tracks these actions to power the dashboard.

---

## The flow in one line

> **Sign in → Set up profile → Browse food → Add to cart (Order) → Pay (Payment) → Engage (Blog / Comment / Vote / Save) → View dashboard.**
